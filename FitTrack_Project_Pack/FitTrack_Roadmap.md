# FitTrack — Development Roadmap

## Phase 0 — Product foundation
- Confirm product name, brand and design system.
- Create React + TypeScript + Vite project.
- Configure Tailwind, Lucide and routing.
- Create responsive app shell and navigation.
- Configure Supabase project and environment variables.
- Document architecture and database migrations.

## Phase 1 — MVP
- Authentication and profile onboarding.
- Age band, experience, goals, equipment and schedule preferences.
- Dashboard shell.
- Exercise library with search and filters.
- Workout plan creation and calendar.
- Workout session logging.
- Calisthenics, gym and weightlifting tracking.
- Personal records and basic progress charts.
- RLS policies and tests.

## Phase 2 — Indian nutrition and broader fitness
- Indian food catalogue and household portions.
- Food diary and recipes.
- Calories/macros with source and estimate labels.
- Hydration tracking.
- Taekwondo training log.
- Cardio, mobility and recovery logs.
- Weekly and monthly reports.

## Phase 3 — Advanced assistance
- AI assistant through a secure server endpoint.
- Editable training suggestions.
- Trend summaries from user logs.
- Wearable / Health Connect integration.
- PDF/CSV export improvements.
- Coach access only with explicit user consent.

## Phase 4 — Production readiness
- Accessibility audit.
- Security and RLS audit.
- Performance and responsive testing.
- Automated tests and error monitoring.
- Privacy policy, terms and data deletion workflow.
- Deployment and backup plan.

## Suggested order
Build and test one complete vertical workflow at a time. Do not start AI, community or wearable integrations before the core logging and privacy flows are reliable.
