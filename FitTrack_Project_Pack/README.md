# FitTrack Project Pack

This package contains:
- `FitTrack_Master_Prompt.txt` — full prompt for an AI coding assistant.
- `FitTrack_Features.md` — product requirements and acceptance criteria.
- `FitTrack_Database.md` — starting database model.
- `FitTrack_Roadmap.md` — staged implementation roadmap.
- `FitTrack_UI_Reference.png` — generated visual inspiration for the dashboard.

## Product decision
FitTrack targets adults aged 18–60+ (not only middle-aged users), with individual plans based on experience, goals, schedule, equipment, food preferences and relevant user-provided limitations.

## Recommended first build
Start with Phase 1 / MVP. Add Indian nutrition, Taekwondo and advanced AI features after the workout tracking foundation is secure and usable.

The reference image is inspiration, not a final design specification. Verify all UI text and data in the actual app.
